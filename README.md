# Desktop Automation Scripts

> A curated suite of personal automation tools and utility scripts designed to streamline business workflows, eliminate repetitive OS tasks, and optimize daily productivity.

---

## 📌 Overview

This repository is a growing collection of modular automation scripts designed to optimize Windows operations. Each script is self-contained and focuses on solving specific desktop friction points—from system-level administration to window management and text expansion.

---

## 📂 Included Scripts & Modules

| File | Hotkey / Trigger | Primary Functionality | Prerequisites |
| :--- | :--- | :--- | :--- |
| **`printer-and-window-manager.ahk`** | `Ctrl + 3`<br>`Ctrl + 1` | • Automatically stops Spooler service, clears jammed queue files, and restarts Spooler.<br>• Pins active window **Always-On-Top** and snaps it to top-left. | Admin Rights *(for Printer Spooler)* |
